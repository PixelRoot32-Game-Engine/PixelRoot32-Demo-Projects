# midway_clone — asset tools

Nothing here is compiled or shipped, and **nothing here is versioned** —
`docs/audits/` is gitignored. These scripts stand in for the PixelRoot32
**Tilemap Editor** and **Sprite Compiler**: they take an authoring format a
human can edit and emit the same C++ those tools emit, into
`games/midway_clone/src/assets/`.

That split is the same one `legend_of_clone` and `metroidvania` have. Their
assets carry a `// Generated by ...` banner and the generator is not in the
repository either. The **output** is what the repo carries and what reviewers
read.

| File | What it is |
| --- | --- |
| `art_source.py` | The authoring format. Every pixel, every palette entry. This is the file you edit. |
| `generate_assets.py` | The exporter. Writes the example's `src/assets/*.h\|.cpp`. |

```bash
python generate_assets.py             # after editing art_source.py
python generate_assets.py --check     # validate and round-trip, write nothing
python generate_assets.py --preview   # print the art back as ASCII
```

The exporter finds the demo as the parent of its own
location. If it is run from a checkout laid out differently, pass the path:

```bash
python generate_assets.py path/to/midway_clone
```

## What the exporter guarantees

Every grid is packed, then **unpacked again and diffed against the source**
before anything is written. A mismatch raises with the offending row printed
both ways. This is not ceremony — the 4bpp format puts the LEFT pixel in the
LOW nibble (`Renderer.cpp:605-606`) and sprite rows are declared `uint16_t`, so
on a little-endian target the hex digits of a literal run in the opposite order
to the pixels they draw. `0x2220` is the pixel run `0,2,2,2`. A transposed
nibble produces a sprite that looks like an art mistake, not a bug.

The level generator also validates its own inputs: an inverted carrier
rectangle or an out-of-bounds island centre raises instead of quietly emitting
an empty region. That check exists because it already caught one —
`CARRIER = (10, 24, 12, 4)` had its columns reversed, so the carrier was
silently never placed and the run reported success.

## Conventions worth knowing before editing art

- **`.` is the transparent hole in every grid.** `legend_of_clone` spells sand
  `.` in its tilemap art; here sand is `a`. A symbol that means *nothing* in one
  file and *beach* in another is a trap worth avoiding.
- **The RGB565 table is indexed by the engine's `Color` enum, not by pixel
  value.** Slots the art never touches keep their conventional color, so
  `Color::Red` still renders red for the debug overlay and error text.
- **Pixel value 0 is never looked up.** The first real color lands at value 1.
- **Player and enemy share no color except black.** On a screen holding a dozen
  aircraft that is what keeps the two apart at a glance. If you add a color to
  one, check it against the other.
- **Nothing on the sprite table may be `#BCBCBC` except the player's
  airframe.** The carrier deck was gray once; the aircraft vanished the moment
  it crossed one. The deck is planked wood now, which is also what wartime
  flight decks actually were.
